# Ayushman HR Compendium

Visual HR placement study chapters with inline diagrams, interactive exercises, recall cards and the full chapter text.

Published chapters:

- Chapter 1: Talent Acquisition, 14 sections.
- Chapter 4: Learning and Development, 13 sections.
- Chapter 7: Organisational Behaviour and Culture, 12 sections.

Open index.html to browse both chapters. Each chapter is a self-contained HTML file and can also be opened on its own.

The site uses inline CSS, JavaScript and SVG, with system fonts and no external runtime dependencies. Reading progress is saved locally in the browser when storage is available.

Evidence limits and source notes are inside each chapter. Conceptual diagrams are labelled as illustrations; company logo cues are simplified. Current legal and policy details should be checked before quoting.

GitHub Pages publishes the main branch from the repository root. No build step is required.
